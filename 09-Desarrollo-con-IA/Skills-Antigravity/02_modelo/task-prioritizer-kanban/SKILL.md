# Nota de creación

Skill generada con modelo en Antigravity.
Solo se definieron manualmente name y description.

# Instrucciones de uso

1. Clasificar cada tarea por impacto y urgencia.
2. Asignar columna: Now, Next o Later.
3. Añadir dependencia y dueño por tarea.

# Control de calidad

- No poner bloqueadas en Now.
- Limitar Now a capacidad real del equipo.
- Incluir criterio de "done" por tarjeta.
