# Nota de creación

Skill generada con modelo en Antigravity.
Solo se definieron manualmente name y description.

# Instrucciones de uso

1. Identificar objetivo del correo (confirmar, pedir, desbloquear, cerrar).
2. Redactar en 5 bloques: saludo, contexto, punto principal, CTA, cierre.
3. Incluir fecha concreta cuando haya acción pendiente.

# Control de calidad

- Evitar ambigüedad en el CTA.
- Mantener tono profesional y breve.
- No incluir tecnicismos innecesarios para negocio.
