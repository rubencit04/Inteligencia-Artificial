# Nota de creación

Skill creada usando la skill de Anthropic vista en clase para generación asistida.

# Instrucciones

Generar registro con:
- Dolor principal
- Caso de uso
- Presupuesto estimado
- Horizonte temporal
- Próximo hito

# Validación

- No dejar campos vacíos sin marca "pendiente".
- Separar dato confirmado vs inferencia.
- Registrar fuente (llamada, email, workshop).
