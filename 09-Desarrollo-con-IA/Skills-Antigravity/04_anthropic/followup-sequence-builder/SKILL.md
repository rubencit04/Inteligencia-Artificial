# Nota de creación

Skill creada usando la skill de Anthropic vista en clase para generación asistida.

# Instrucciones

1. Definir estado de oportunidad.
2. Crear mensajes por día (D+1, D+3, D+7).
3. Variar enfoque: valor, prueba social, cierre.

# Validación

- No repetir el mismo texto entre toques.
- Incluir CTA distinto en cada paso.
- Evitar tono agresivo de venta.
