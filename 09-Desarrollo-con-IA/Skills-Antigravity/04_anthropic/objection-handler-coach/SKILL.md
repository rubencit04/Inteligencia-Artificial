# Nota de creación

Skill creada usando la skill de Anthropic vista en clase para generación asistida.

# Instrucciones

Para cada objeción:
1. Reconocer preocupación.
2. Reencuadrar con dato o evidencia.
3. Proponer opción concreta.
4. Cerrar con pregunta de avance.

# Validación

- Nunca responder de forma defensiva.
- Evitar promesas no controlables.
- Forzar siempre un siguiente paso.
