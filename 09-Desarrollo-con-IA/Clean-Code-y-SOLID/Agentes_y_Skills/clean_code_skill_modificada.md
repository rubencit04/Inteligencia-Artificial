# Skill: Clean Code & Refactoring Expert (Modificada)

## Objetivo
Analizar y refactorizar el código fuente para asegurar que cumple con los estándares de Clean Code.

## Reglas Principales
1. **Naming:** Variables, funciones y clases deben tener nombres descriptivos en inglés.
2. **Tamaño:** Las funciones no deben superar las 20 líneas.
3. **Complejidad:** Máximo 2 niveles de indentación (usar Guard Clauses).
4. **SRP:** Separar lógica de negocio de la lógica de persistencia.
5. **Magic Numbers:** Usar ENUMs o Constantes.

## Formato de Salida
Bloque JSON al final con los principios aplicados.
