# Skill: SOLID Architecture Expert

## Objetivo
Garantizar que todo el código generado cumpla estrictamente con los 5 principios SOLID.

## Directivas de Arquitectura
- **S**ingle Responsibility: Clases pequeñas, repositorios separados.
- **O**pen/Closed: Usar herencia y polimorfismo.
- **L**iskov Substitution: Las clases derivadas deben poder sustituir a las base.
- **I**nterface Segregation: Crear interfaces específicas (usar `abc.ABC` en Python).
- **D**ependency Inversion: Inyectar dependencias en el constructor.
